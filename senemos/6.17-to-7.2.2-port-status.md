# Nabu 6.17 to 7.2.2 port status

This table is the source and HIL status ledger for the `7.2.2-test` branch.
"Built" means that the merged Fedora/Nabu configuration completed `Image`,
Nabu DTB and module compilation.  It never means that physical hardware has
passed.  HIL results must be recorded against the gates in
`7.2.2-hil-plan.md`.

## Current release boundary

Source commit `5f7d3ab7b57a` passed source hygiene, changed-object compilation,
full `Image`/DTB/modules compilation, changed binding/DTB schema checks and the
pruned RPM gate.  COPR build `10934934` succeeded on Fedora 43, 44, 45 and
Rawhide AArch64.  The Rawhide binary RPM is 17,595,118 bytes, down from
106,571,348 bytes for broad-config build `10932982`; the four complete build
times fell from about 96-116 minutes to 18-20 minutes.  Its COPR OpenPGP
signature, header and payload digests passed, and the exact EVR resolved with
the Fedora Rawhide AArch64 plus Nabu COPR repositories.

GitHub uses `7.2.2` as the default source branch.  Publication evidence closes
G1 only: installation remains a separate test boot choice until USB-first G2
and the later HIL gates pass.  Keep Android and the known-good 6.17 boot entry
available.
